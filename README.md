# StreamFinder

A simple Progressive Web App that helps you find which of your subscribed streaming services has a title and open it, with a copyable search prompt as a fallback.

## Features
- Select your subscribed services (saved locally)
- Search for movies/shows using JustWatch public data
- See only matches from your selected services
- Copy title or open the service directly
- Quick login/home links for each service

## Use on Android
1. Open the GitHub Pages site (or the raw index.html)
2. In Chrome: menu → Add to Home screen / Install app
3. Select your services in the My Services tab and save
4. Search

This is an efficiency tool — it does not maintain logins or guarantee perfect deep links.
